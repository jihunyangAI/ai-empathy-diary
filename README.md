# AI 공감 다이어리

한 줄 일기를 쓰면 AI가 감정을 분석하고 공감·위로의 말을 건네는 앱입니다.
추가 설치 없이 Node.js(18 이상) 하나로 실행됩니다.

## 준비

프로젝트 폴더에 `.env` 파일을 만들고 OpenRouter API 키를 넣습니다. (`.env.example` 참고)

```
OPENROUTER_API_KEY=sk-or-...
```

선택 변수

| 변수 | 설명 |
| --- | --- |
| `PORT` | 서버 포트 (기본 3000). 바꾸면 `file://`로 연 index.html은 동작하지 않으니 http 주소로 접속하세요. |
| `OPENROUTER_PRIMARY_MODEL` | 1순위 모델 교체 (기본 `deepseek/deepseek-v4-pro`) |
| `OPENROUTER_FALLBACK_MODELS` | 추가 폴백 모델, 쉼표로 구분 |

## 실행

```
node server.js
```

그다음 둘 중 편한 방법으로 엽니다.

- 브라우저에서 http://localhost:3000 접속
- `index.html` 파일을 더블클릭해 바로 열기 (서버는 켜 둔 상태여야 합니다)

종료는 터미널에서 `Ctrl + C`.

## 모델과 비용

- 1순위는 저가 유료 모델 `deepseek/deepseek-v4-pro`입니다. 일기 1건당 대략 1천 토큰 안팎이라 비용은 1원 미만 수준입니다. (OpenRouter 크레딧 필요)
- 유료 모델이 실패하거나 크레딧이 없으면 무료 모델(nemotron, gemma)로 자동 전환됩니다. 무료 모델은 느리거나 혼잡할 수 있습니다.
- 한 요청은 최대 약 40초 안에 응답하며, 모든 모델이 실패하면 "잠시 후 다시 시도해 주세요" 안내가 표시됩니다.

## 참고

- 일기는 서버에 저장되지 않고 사용하는 브라우저(localStorage)에만 저장됩니다. `http://localhost:3000`과 `file://`로 연 페이지는 저장 공간이 서로 다릅니다.
- 일기는 500자까지 쓸 수 있습니다.
- 힘든 마음을 표현하면 자살예방상담전화 109, 정신건강위기상담전화 1577-0199 안내가 함께 표시됩니다. AI의 말은 전문 상담을 대신하지 않습니다.
